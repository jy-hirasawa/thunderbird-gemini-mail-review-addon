# Supporto internazionalizzazione (i18n)

[English](../en/I18N.md) | [日本語](../ja/I18N.md) | [Deutsch](../de/I18N.md) | [Français](../fr/I18N.md) | [简体中文](../zh_CN/I18N.md) | Italiano

## Panoramica
Il componente aggiuntivo Gemini Mail Review supporta ora l'internazionalizzazione, mostrando automaticamente l'interfaccia utente nella lingua corrispondente alle impostazioni della lingua di Thunderbird.

## Lingue supportate
- **English (en)** - Lingua predefinita
- **Japanese (ja)** - 日本語対応
- **German (de)** - Deutsch-Unterstützung
- **French (fr)** - Support français
- **Simplified Chinese (zh_CN)** - 简体中文支持
- **Italian (it)** - Supporto italiano

## Funzionalità
- Rilevamento automatico della lingua in base alle impostazioni locali di Thunderbird
- Fallback all'inglese se le impostazioni locali correnti non sono supportate
- Tutti gli elementi dell'interfaccia utente sono tradotti, tra cui:
  - Nome e descrizione dell'estensione
  - Pagina delle opzioni (impostazioni)
  - Interfaccia popup (revisione email)
  - Pulsanti, etichette e messaggi
  - Messaggi di errore e testo di stato

## Dettagli di implementazione

### Struttura delle directory
```
_locales/
├── en/
│   └── messages.json    # Traduzioni inglesi
├── ja/
│   └── messages.json    # Traduzioni giapponesi
├── de/
│   └── messages.json    # Traduzioni tedesche
├── fr/
│   └── messages.json    # Traduzioni francesi
├── zh_CN/
│   └── messages.json    # Traduzioni in cinese semplificato
└── it/
    └── messages.json    # Traduzioni italiane
```

### Come funziona
1. Il componente aggiuntivo utilizza l'API WebExtension `browser.i18n`
2. Thunderbird rileva automaticamente la sua impostazione locale corrente
3. Il componente aggiuntivo carica il file `messages.json` corrispondente
4. Tutto il testo dell'interfaccia utente viene sostituito con stringhe localizzate in fase di esecuzione
5. Se un'impostazione locale non è supportata, viene utilizzato l'inglese per impostazione predefinita

## Come testare

### Cambiare la lingua di Thunderbird
1. Apri Thunderbird
2. Vai su **Impostazioni** > **Generale** > **Lingua**
3. Seleziona la tua lingua preferita (inglese, giapponese, italiano, ecc.)
4. Riavvia Thunderbird
5. Apri le opzioni o il popup del componente aggiuntivo - verrà mostrato nella lingua selezionata

### Verificare il supporto linguistico
1. Installa il componente aggiuntivo in Thunderbird
2. Testa con le impostazioni locali inglesi:
   - Imposta la lingua di Thunderbird su inglese
   - Riavvia Thunderbird
   - Apri le impostazioni del componente aggiuntivo - dovrebbe mostrare in inglese
3. Testa con le impostazioni locali italiane:
   - Imposta la lingua di Thunderbird su italiano
   - Riavvia Thunderbird
   - Apri le impostazioni del componente aggiuntivo - dovrebbe mostrare in italiano

## Aggiungere nuove lingue

Per aggiungere il supporto per lingue aggiuntive:

1. Crea una nuova directory delle impostazioni locali:
   ```bash
   mkdir -p _locales/{locale_code}/
   ```

2. Copia il file dei messaggi inglesi come modello:
   ```bash
   cp _locales/en/messages.json _locales/{locale_code}/messages.json
   ```

3. Traduci tutti i valori dei messaggi nel nuovo file `messages.json`:
   ```json
   {
     "extensionName": {
       "message": "La tua traduzione qui",
       "description": "Name of the extension"
     },
     ...
   }
   ```

4. Testa impostando Thunderbird sulle nuove impostazioni locali

### Esempio: Aggiunta del supporto spagnolo
```bash
mkdir -p _locales/es/
cp _locales/en/messages.json _locales/es/messages.json
# Modifica _locales/es/messages.json e traduci tutti i valori "message" in spagnolo
```

## Dettagli tecnici

### API utilizzate
- `browser.i18n.getMessage(messageName)` - Ottieni una stringa localizzata
- `browser.i18n.getUILanguage()` - Ottieni le impostazioni locali correnti (facoltativo)

### File modificati
- `manifest.json` - Aggiunto `default_locale` e segnaposto i18n
- `options.html` - Aggiunti attributi `data-i18n` agli elementi di testo
- `options.js` - Aggiunta funzione `localizeUI()` per caricare le stringhe localizzate
- `popup.html` - Aggiunti attributi `data-i18n` agli elementi di testo
- `popup.js` - Aggiunta funzione `localizeUI()` per caricare le stringhe localizzate

### Processo di localizzazione
1. La pagina si carica, l'HTML contiene testo inglese come fallback
2. La funzione `localizeUI()` viene chiamata su `DOMContentLoaded`
3. La funzione interroga tutti gli elementi con attributi `data-i18n`
4. Per ogni elemento, ottiene il messaggio localizzato usando `browser.i18n.getMessage()`
5. Aggiorna il `textContent` o il `placeholder` dell'elemento con la stringa localizzata

## Compatibilità del browser
- Thunderbird 102.0 e successivi (supporto completo)
- Tutti i browser moderni compatibili con WebExtension (se portato)

## Note
- L'implementazione i18n segue gli standard WebExtension di Mozilla
- Tutte le stringhe sono memorizzate in formato JSON per una facile manutenzione
- Il sistema è estensibile - nuove lingue possono essere aggiunte senza modifiche al codice
- Il fallback garantisce che il componente aggiuntivo funzioni sempre, anche con impostazioni locali non supportate
